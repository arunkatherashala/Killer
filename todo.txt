## Feature 1: Compression for Killer

**What it is**: Expose compression/encoding as native Killer language builtins so users can write:
```killer
compressed = compress("hello world hello world", "rle")
original = decompress(compressed, "rle")
encoded = b64_encode("secret data")
decoded = b64_decode(encoded)
```

**What already exists**: `src/compression_module.rs` already has RLE, base64, and hex in pure Rust — just not wired into the language as builtins. No external crates needed.

**Missing piece**: LZ77 sliding-window compression (pure stdlib Rust) + wiring everything into `builtin.rs` and `compiler.rs`.

---

## Feature 2: Killer Debugging + Auto-Correction

**What it is**: Two new builtins:
- `debug_check(code)` — scans your Killer source, returns a list of detected issues (missing `kfn`, unclosed braces, wrong syntax, undefined vars)
- `auto_fix(code)` — returns a corrected version of the source code automatically

**What already exists**: `src/debugger.rs` has a basic interactive debugger (breakpoints, step/next/continue) but variable inspection and auto-fix are stubs with no real implementation.

**Missing piece**: An error pattern matcher that recognizes common Killer mistakes and suggests/applies fixes.

---

## Feature 3: Polyglot `@lang{}` Syntax

**What it is**: Write and execute any language directly inside a `.killer` file:
```killer
result = @python {
    x = 10 * 5
    print(x)
}

@java {
    System.out.println("Hello from Java!");
}

@bash {
    echo "disk usage:"
    df -h
}
```

**What already exists**: The lexer already emits `TokenKind::At` for `@` — but it does nothing with the identifier after it. No parser rule, no polyglot executor exists.

**Missing pieces**:
1. `src/polyglot.rs` — new file that detects installed runtimes (python, java, node, go, bash, etc.), writes code to a temp file, runs it via `std::process::Command`, returns stdout as a `String`
2. Lexer extension: `@java` → emit `LangAnnotation("java")` instead of just `At`
3. Parser rule: `@lang { ... }` → compiles to `polyglot_exec("lang", "code_block")`
4. Builtins: `polyglot_exec(lang, code)` and `polyglot_list()` (lists all detected runtimes)

---

## Key Constraint Across All 3

**Zero external crates** — Cargo.toml has no dependencies due to corporate SSL policy. Everything must be pure `std` Rust.
