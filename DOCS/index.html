Quick Start

git clone https://github.com/ArunKathera/killer && cd killer/SOURCE/src/v2-rust/killer && cargo build --release

Produces a single binary: killer-native (Windows: killer-native.exe)

hello.killer
// Hello World in Killer
let name = "World"
print(K"Hello {name}!")

// Define a function
kfn greet(person) {
    return K"Welcome, {person}!"
}

// Use built-in regex
let has_email = regex_match("user@killer.dev", "\\w+@\\w+\\.\\w+")
print(K"Valid email? {has_email}")

// Built-in database
let db = db_open("app.kdb")
db_set(db, "user:1", "Alice")
print(db_get(db, "user:1"))
db_close(db)
Run it
$ killer-native hello.killer
Hello World!
Valid email? true
Alice

Everything Built-In

📦

Package Manager

Full dependency management with pkg_init(), pkg_add(), pkg_install(). Reads killer.toml, resolves semver, installs to packages/.

🔍

LSP Server

IDE integration with lsp_start(). Provides diagnostics, completions, hover docs, formatting. JSON-RPC over TCP.

🐛

Debugger (DAP)

Step debugging with dap_start(), breakpoints, variable inspection, call stack, expression evaluation.

📚

Docs Generator

Auto-generate HTML documentation from source with docs_generate(). Searchable, dark-mode, serves on HTTP.

🔤

Regex Engine

NFA-based regex with regex_match(), regex_find_all(), regex_replace(). Supports groups, anchors, character classes.

💾

File Database

Persistent key-value store with db_open()/db_set()/db_get(). Prefix queries, JSON serialization, zero setup.

🎨

Formatter + Linter

fmt(code) auto-indents. lint_code(code) catches errors statically. Like gofmt + clippy in one.

🌐

HTTP Client/Server

Built-in http_get(), http_post(), HTTP server. No external framework needed.

🤖

AI/ML Engine

Native ML primitives, TF-IDF embeddings, vector memory, LLM integration. 2,771 lines of ML code built-in.

🗜️

Nova Compression

Custom codec that beats Apache Parquet. 84% reduction on CSV. Bit-packed dicts, adaptive codecs, parallel encoding.

🔒

Encryption

AES-256-GCM, SHA-256, HMAC, secure random — all built-in. No OpenSSL dependency.

⚡

Performance

13-50M loop ops/sec. Fused instructions, slot-based variables, compile-time optimization. JIT compiler included.

Code Examples

Package Management
pkg_init("my-app", "1.0.0")
pkg_add("killer-http", "^1.0.0")
pkg_add("killer-json")
pkg_install()
print(pkg_list())
Debug a Program
dap_start("app.killer")
dap_break(10)          // breakpoint at line 10
dap_continue()         // run until breakpoint
print(dap_vars())      // inspect variables
print(dap_stack())     // call stack
dap_step()             // step one line
dap_stop()
Generate Documentation
docs_generate("./src", "docs")   // scan → HTML
docs_serve(8080)                    // http://localhost:8080
docs_export("json")                // → docs/api.json
Import Modules
let utils = import("./utils")         // local file
let http  = import("killer-http")     // installed package
let math  = import("std:math")        // standard library
print(import_list())                  // all available modules

Self-Documenting

// Get help on any function
print(help("regex_match"))

// Search for functions
print(help_search("sort"))

// Tab-complete in REPL
print(repl_complete("reg"))
// → ["regex_match", "regex_find", "regex_find_all", ...]

// "Did you mean?" on typos
print(suggest("pritln"))
// → Did you mean: println()?
