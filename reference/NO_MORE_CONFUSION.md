**Do this every time you need to add/update something:**


---

## RULE 5: WHEN CONFUSED ABOUT FILES

```
"Should I create NEW file or UPDATE old file?"

Ask yourself:

1. Does similar file already exist?
   YES  → Update that file (don't create new)
   NO   → Create new file (it's truly new purpose)

2. Have I seen a file like this before?
   YES  → Update it (same purpose, more data)
   NO   → Create new (truly new purpose)

3. Will I update this file again next week/month?
   YES  → Creating one file now (will keep updating)
   NO   → Don't create (temporary - use existing)

WHEN IN DOUBT: Update existing, don't create new
```
