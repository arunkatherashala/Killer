# 🤖 Multi-Agent Framework - Main Index

Welcome to the **Killer Multi-Agent Framework**!

## 🚀 Quick Start (5 minutes)

### 1. Read the Framework
```bash
open framework/AGENT_FRAMEWORK.md
```

### 2. Pick Your Template
- **For quick decisions**: `agent_template_4.killer`
- **For proofs/research**: `agent_template_24.killer` (recommended)
- **For large projects**: `agent_template_72.killer`
- **For institutional validation**: `agent_template_108.killer`

### 3. Customize
```bash
cp templates/agent_template_24.killer my_problem.killer
# Edit: problem_statement, attack strategies, validation logic
```

### 4. Deploy
```bash
killer.exe my_problem.killer
```
