## What is the Multi-Agent Framework?

The **Killer Multi-Agent Framework** enables you to deploy **organized teams of AI agents** to solve ANY problem through:

✅ **Scalable Tiers** - 4-agent, 24-agent, 72-agent, 108-agent configurations

## Quick Start

### 1. Choose Your Scale

```
24-Agent (Professional)    - $1K problem (3-5 hours)
72-Agent (Enterprise)      - $10K problem (1-2 days)
108-Agent (Institutional)  - $100K problem (1-2 weeks)
```

### 2. Adapt the Template

```killer
kfn main() {
  // Load 24-agent template
  template = load_24_agent_template()
  
  // Customize for YOUR problem
  template.problem_statement = "Your theorem here"
  template.proof_method = your_validation_function
  template.success_criteria = your_acceptance_rules
  
  // Deploy agents
  agents = template.deploy()
  
  // Run orchestration
  result = agents.orchestrate_consensus()
  
  // Get results
  print(result)
}
```

### 3. Run

```bash
killer.exe your_problem.killer
```

## Templates Available

### **4-Agent Template** (`agent_template_4.killer`)
For systems with basic specialization:
- Validator Agent
- Benchmark Agent
- Documentation Agent
- Quality Auditor Agent

**Use for**: Small-scale validation, quick proofs, business decisions

### **24-Agent Template** (`agent_template_24.killer`)
For professional-grade consensus:
- 5 Attack Agents (try to break proof)
- 19 Support Agents (validate from different angles)

**Use for**: Millennium Problems, mathematical theorems, complex proofs

### **72-Agent Template** (`agent_template_72.killer`)
For enterprise-scale validation:
- Tier 1: 24 agents (core debate)
- Tier 2: 48 agents (expanded validation)

**Use for**: Large research projects, institutional validation

### **108-Agent Template** (`agent_template_108.killer`)
For maximum consensus strength:
- Tier 1: 24 agents (core)
- Tier 2: 48 agents (expansion)
- Tier 3: 36 agents (enterprise tier)

**Use for**: Critical decisions, multi-institutional validation, breakthrough discoveries
