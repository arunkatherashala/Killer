# Language Comparison Benchmarks

Legacy benchmarks for comparing performance across different programming languages.

## Files

- **benchmark.py** - Python benchmark implementation
- **benchmark_csharp.cs** - C# benchmark implementation  
- **benchmark_rust.rs** - Rust benchmark implementation

## Tests Performed

1. **Loop Test** - 100,000 iterations
2. **Arithmetic Test** - 50,000 operations
3. **Array Test** - 10,000 elements
4. **Recursion Test** - fibonacci(20)
5. **String Concatenation** - 1,000 operations
6. **Nested Loops** - 100x100 iterations

## Note

These are generic language benchmarks for development/testing purposes. For Killer-specific performance testing, see the main performance test files in the root directory.
