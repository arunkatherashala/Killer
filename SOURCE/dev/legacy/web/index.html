#!/usr/bin/env killer
# Basic Data Types
age = 25;
score = 99.5;
print(age);

# String Methods
message = "Hello, World!";
print(`Uppercase: "${message.toUpperCase()}"`);

# Array Methods
numbers = [1, 2, 3, 4, 5];
doubled = numbers.map(x => x * 2);
print(`Doubled: ${doubled}`);

# Arrow Functions
add = (a, b) => a + b;
print(`Add(10, 5): ${add(10, 5)}`);

# Control Flow
score = 85;
if score >= 80 {
    print("Grade: B");
}

# Classes & Inheritance
class Animal {
    constructor(name) {
        this.name = name;
    }
    speak() { return "Sound"; }
}

class Dog extends Animal {
    speak() { return "Woof!"; }
    static breeds() { return "400+ breeds"; }
}

max = new Dog("Max");
print(max.speak());

Why Killer?

Killer is a modern programming language designed from scratch with a focus on simplicity and modern syntax. It features:

  • ✨ Modern Syntax: Arrow functions, template literals, and destructuring
  • 🏗️ Full OOP: Classes with inheritance, static methods, getters, and setters
  • 🎯 Powerful Built-ins: 14+ string methods, 9+ array methods, Math object
  • 🔄 Multi-Target Compilation: Run directly, transpile to Python or JavaScript
  • 📚 Type System: Dynamic typing with typeof, instanceof, and Array.isArray()
  • 🐛 Error Handling: try/catch/finally blocks
  • 💻 Regular Expressions: Full regex support with pattern matching
