# Playground Scripts

This folder contains ad-hoc demo and scratch Killer scripts.

## Quick Run

From project root:

- `python main.py experimental/index.killer`
- `python main.py experimental/calculator.killer`
- `python main.py experimental/myprogram.killer`
- `python main.py experimental/practical_example.killer`
- `python main.py experimental/view.killer`

## Notes

- These are not core runtime files.
- They are useful for quick manual checks and demos.
- Formal regression tests live under `tests/`.
