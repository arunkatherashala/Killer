## 💎 The Core Feature

**Killer is the ONLY language supporting both:**

```killer
// Python style (indentation)
fn fibonacci(n)
    if n <= 1
        n
    else
        fibonacci(n - 1) + fibonacci(n - 2)

// Go style (braces)
fn fibonacci(n) {
    if (n <= 1) {
        n
    } else {
        fibonacci(n - 1) + fibonacci(n - 2)
    }
}

```

## ✨ Standout Features

### 1. Dual Syntax (Unique)
```killer
// Use Python style for clean scripts
fn process(data)
    for item in data
        print(item)

// Use Go style for complex systems  
fn process(data) {
    for item in data {
        if item["valid"] {
            process_item(item)
        }
    }
}

// Mix in real code - both are the same language!
```

### 2. Rich Standard Library
```killer
text = "  hello world  "
print(upper(trim(text)))      // "HELLO WORLD"
print(split(text, " "))       // ["hello", "world"]

numbers = [3, 1, 4, 1, 5]
print(reverse(numbers))       // [5, 1, 4, 1, 3]
print(join(numbers, "-"))     // "3-1-4-1-5"
```
